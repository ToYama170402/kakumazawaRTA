# 確定した内部設計仕様

- 経路・種目の管理：起動時に同期を行う端末内局所記憶方式。通信圏外での完全な動作を保証。
- 位置情報の取得と保護：1秒周期の定時取得。端末の安全な暗号鍵管理領域（Keystore/Keychain等）で動的生成した鍵による暗号化保存。
- 自動終了判定：境界長方形による終点判定。
- 不正検知規則：5秒の移動窓を用いた区間速度算出。状態属性（公認・参考・無効）による記録管理。
- データ送信制御：局所蓄積表による一貫性管理。一意の識別子による重複防止と、指数関数的退避を伴う背景処理による再送。
- 階級評価手順：端末側での暫定階級表示（即応性）と、管理用計算機検証後の公認階級更新による二段階評価。
- 順位表集計構造：期間識別子を付与した単一記録表の運用。「期間識別子・学域学類コード・走行時間」の複合索引による高速動的集計。
