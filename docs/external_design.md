# 『角間坂RTA』外部設計仕様書（確定版）

## 1. 画面構成と基本遷移（アーケード直感方式）

むだな階層を排除し、走行への即応性とゲーム機的な高揚感を重視した画面設計とする。

- メイン画面（計測準備）
  - 起動時に即座に表示。
    - 種目選択：「徒歩」「自転車」等のカテゴリを切り替える操作部。
    - 計測開始： 挑戦を開始する巨大な主ボタン。
    - 画面を横に払う（スワイプ）ことで「順位表画面」へ即座に切り替わる構造。
- 計測中画面（安全第一・ロック状態）
  - 画面注視を防止するため、経過時間と停止ボタンのみを表示。
  - 開始時、中間地点通過時、ゴール時に音声と振動で状態を通知。
  - ネームエントリー画面（走行終了直後）
  - 走行完了後に必ず遷移。
  - 初回および2回目以降も毎回表示され、前回の「名前（ニックネーム）」と「所属学域・学類」が初期値として入る。確定ボタンで記録を送信。
- 順位表画面（ランキング）
  - 「今月の順位（定期初期化）」と「歴代殿堂（永続）」を切り替え可能。
  - 学域・学類別の抽出（フィルタリング）機能を備え、組織間の対抗戦を可視化。

## 2. 計測および判定仕様（GPS・サーバー検証）

位置情報を利用しつつ、不正を排除し、山間部の通信環境にも耐える堅牢な計測を行う。

- 手動開始・自動終了
  - ふもとで「計測開始」を契機に位置情報の監視を起動。
  - 運営側が事前定義した複数ルートの「終点領域（ポリゴン）」への進入を検知した瞬間に自動で計測を停止。
- 通信圏外への対応（一時保存）
  - 走行中のGPSログ（位置・時刻の配列データ）を端末内に暗号化して一時保持。
  - 通信復帰時にネームエントリーを促し、ログをサーバーへ一括送信。
- 不正防止（足切り）
  - 端末の算出タイムではなく、送信されたGPSログをサーバー側で再検証して走行時間を公認。
  - 各カテゴリの物理的限界を超える最高速度や平均速度（乗り物利用）を検知した場合、自動的に「参考記録」として扱い、順位表から除外。

## 3. 評価および競技レギュレーション

明確な標的と、飽きのこない時間軸の設計により、挑戦の継続性を担保する。

- 絶対評価階級制
  - 区間ごとに物理的なタイム閾値を設定（例：〇分未満はS級、〇分未満はA級）。
  - 走行直後、ネームエントリー完了と同時に確定した階級を画面に大書して演出。
- 順位表の運用周期
  - 月単位で現行の順位表を初期化（毎月1日JST時点）。
  - 過去の最高記録は「歴代殿堂」として永続的に保存し、いつでも閲覧可能。
